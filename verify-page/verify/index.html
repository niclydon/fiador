Fiador — human-backed attestation for Discord bots. Opening a preview link starts a fresh browser check; the preview itself is only a snapshot from crawl time.

What this check can tell you

A passing wallet check means a unique human registered the wallet that signed a claim naming a Discord application. It does not establish that the signer controls that application, identify the human, prove a human wrote a message, or judge the bot’s behavior. Until application control has independent proof, the result is Claim unconfirmed.

Previews can stay cached after expiry or revocation, and lookalike domains can imitate a card. Rely on a fresh check at the canonical fiador.org domain for the current status.

Checks run in your browser. This page has no analytics or third-party assets. It contacts only the registry, attestation host, and RPC endpoint used for a check you start (including a check started by opening a prefilled link). Those hosts receive the request and may log it. Hosts without cross-origin access can block a browser fetch; paste the public signed JSON as the fallback. Operators should serve attestation JSON with Access-Control-Allow-Origin: *.
